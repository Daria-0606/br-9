# ЛР2. Неизменяемая запись журнала

Вариант: **Ledger**.

## Что дано

Записи успешно добавляются в журнал, но нулевая сумма пока допустима, поля уже созданной записи можно изменить, а наружу необходимо безопасно выдавать коллекцию записей.

## Задание

### Шаг 1. Защитите `LedgerEntry`

`amount` должен быть строго больше нуля. Нулевая сумма вызывает `INVALID_AMOUNT`. После создания публичные поля записи нельзя изменять.

Используйте уже предоставленную заготовку `dataclass(frozen=True)` или свойства только для чтения. Сложный собственный `__setattr__` писать не нужно. Вложенный `Money` уже неизменяем.

### Шаг 2. Не заменяйте существующую запись

Повторный `entry_id` должен обрабатываться готовым хранилищем и вызывать `DUPLICATE_ENTRY`. Существующая запись при этом остаётся на месте. Одинаковая `transaction_id` с другим `entry_id` допустима.

### Шаг 3. Не отдавайте изменяемую коллекцию журнала

При чтении списка записей возвращайте `tuple`. Изменение полученного контейнера не должно позволять добавить, удалить или заменить элементы внутри журнала.

## Примеры и границы

- Нулевая сумма отклоняется.
- Попытка изменить `amount` или `entry_type` уже созданной записи запрещена.
- Повтор `E1` даёт `DUPLICATE_ENTRY` и не меняет число записей.
- Та же транзакция с новым `entry_id` допустима; наружу выдаётся неизменяемый контейнер.

## Дополнительное задание

**Выборка записей счёта в одной валюте.** Добавьте `LedgerService.entries_for_account(account_id, currency)`: метод возвращает `tuple` записей выбранного счёта и валюты в порядке добавления. Для параметра валюты допустимо имя `code`, чтобы использовать готовый одноимённый проверяющий метод `currency`.

Неизвестная валюта вызывает `INVALID_CURRENCY`, пустая выборка даёт `()`. Метод не меняет журнал, не создаёт новые операции и не копирует сами объекты записей.

Проверка: `python check.py lab02 --bonus`.
